# Portfólio

Portfólio pessoal desenvolvido para apresentar meus projetos, habilidades e formas de contato em uma interface moderna, organizada e com identidade visual mais marcante.

## Visão Geral

Este projeto foi criado para funcionar como minha vitrine profissional na web, reunindo projetos relevantes, competências técnicas e informações de contato em uma navegação simples e direta. Pelo histórico de commits, o site evoluiu com foco em componentização, organização dos dados, identidade visual e melhor manutenção do código.

## Principais Funcionalidades

- Seção inicial (`Hero`) com apresentação pessoal.
- Opção de download do currículo.
- Seção de projetos com dados organizados em estrutura própria.
- Inclusão de projetos como Painel E-SUS, UniPass e Santa Casa.
- Seção de habilidades categorizadas.
- Uso de ícones para tecnologias e competências.
- Link de navegação para a seção de skills no cabeçalho.
- Seção de contato com conteúdo e estilo atualizados.
- Rodapé (`Footer`) para fechamento da página.
- Metadados de layout ajustados.
- Animação de fundo com estilo futurista.
- Melhorias de legibilidade e manutenção da estrutura do código.

## Estrutura da Página

- `Header`: navegação principal entre as seções.
- `Hero`: apresentação inicial com destaque para perfil profissional e currículo.
- `Projects`: listagem dos principais projetos com descrição e tecnologias.
- `Skills`: exibição de habilidades separadas por categorias.
- `Contact`: área para contato e conexão profissional.
- `Footer`: encerramento visual da página.

## Tecnologias e Recursos

- Next.js
- React
- Font Awesome
- SVGs personalizados para projetos e ícones
- Estrutura baseada em componentes reutilizáveis

## Objetivo do Projeto

O objetivo do portfólio é centralizar minha apresentação profissional em um único lugar, facilitando a visualização de:

- projetos desenvolvidos;
- habilidades técnicas;
- tecnologias com as quais já trabalhei;
- formas de contato;
- evolução da minha identidade como desenvolvedor.

## Diferenciais do Projeto

- Layout pensado para apresentação profissional.
- Estrutura componentizada para facilitar evolução futura.
- Conteúdo organizado por seções claras.
- Destaque visual para projetos reais desenvolvidos.
- Identidade mais moderna com animações e ícones personalizados.
